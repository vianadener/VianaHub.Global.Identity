## Uso esperado

- O **PO** recebe a solicitação inicial da feature.
- O **Tech Lead** refina o design técnico.
- O **QA** prepara e valida os testes.
- O **Developer** implementa a feature.
- O **Security** revisa riscos e exposição.
- O **Codex CLI** orquestra as etapas até o merge em `develop`.
